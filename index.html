How it works
  1. Imagine each object is made of perfectly stretchy clay.
  2. You may bend, stretch and squash it — never tear it or glue parts together.
  3. Count the holes that go all the way through. That's the genus: sphere 0, torus 1, double torus 2…
  4. Dents don't count. Something with n openings into one hollow space (a shirt, a pipe) has genus n − 1.
